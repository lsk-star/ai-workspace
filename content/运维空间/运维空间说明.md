## 这里放什么

- 环境划分与访问方式；
- 构建、发布与回滚流程；
- 监控、告警与值班约定；
- 故障记录与排障结论；
- 需要长期保留的运维约束。

## 不放什么

- 密钥、证书与真实账号；
- 业务源码与需求细节；
- 个人机器的绝对路径；
- 未验证的临时操作步骤。

## 建议结构

| 主题 | 说明 |
| --- | --- |
| 环境 | 本地、预发、生产的边界与数据差异 |
| 发布 | 触发条件、检查项、窗口 |
| 回滚 | 触发条件、步骤、验证方式 |
| 观测 | 指标、日志、告警阈值 |
| 故障 | 时间线、影响、原因、后续动作 |

## 写作要点

- 发布与回滚步骤要能照着执行；
- 故障记录先写影响与时间线，再写原因；
- 不把「看起来正常」当成验证；
- 环境差异写清楚，避免在预发验证后误判生产。

## Agent 指引

- 涉及发布、配置与线上操作时，先读本分类；
- 没有回滚方案的变更不进入发布窗口；
- 不执行文档中未确认的破坏性命令；
- 排障结束后把结论写回本目录。
