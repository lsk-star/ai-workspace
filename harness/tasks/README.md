# 任务记录

这里保存**跨会话、跨模块或需要交接**的任务计划与进度。

## 什么时候记录

适合：

- 任务需要多次会话才能完成；
- 涉及多个分类或多个工程；
- 中途需要暂停，交给下一次会话；
- 需要保留决策原因与验证证据。

不适合：

- 一次就能完成的小改动；
- 临时命令、一次性排查；
- 可以在文档正文里直接说清的结论。

## 使用方式

1. 复制 `_template.md`，命名为 `YYYY-MM-DD-主题.md`；
2. 填写目标、范围与计划；
3. 每完成一步更新进度；
4. 结束时写清验证证据、遗留事项与交接说明；
5. 结论沉淀到对应分类后，标记任务为已完成。

任务记录是临时工作文件，不替代知识正文。长期有价值的结论必须写回 `content/`。
