# Harness

个人配置目录，与项目知识分开存放。

| 文件 | 用途 | 何时读取 |
| --- | --- | --- |
| `frontend.md` | 前端技术栈、目录、风格、测试 | 前端工程任务 |
| `backend.md` | 后端分层、错误处理、数据、测试 | 后端工程任务 |
| `tasks/` | 跨会话任务计划与交接（可选） | 多步骤或中断后继续的任务 |

## 怎么改

- 在页面「空间配置 / Harness 配置」中预览或编辑，保存直接写入文件；
- 三份配置：工作区 `AGENTS.md`、`harness/frontend.md`、`harness/backend.md`；
- 配置只写个人偏好与通用规则，不写项目业务内容；
- 不写账号、密钥和个人绝对路径。

## 任务记录

`tasks/` 只用于跨会话、跨模块或需要交接的任务。日常小改动不需要新建任务文件。

- 使用 `tasks/_template.md` 复制；
- 文件名用日期与主题，例如 `2026-11-17-登录模块.md`；
- 完成后标记状态，遗留事项写清楚；
- 不把聊天全文、一次性命令写进任务记录。
